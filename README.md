# How to Install Netrunner IRL on Your Android Phone

### 1. Download the APK
- Get the file named **Netrunner IRL.apk** and save it to your phone (usually it lands in the Downloads folder).

### 2. Allow Installation from Unknown Sources
- Open **Settings**.
- Go to **Apps → Special app access → Install unknown apps**  
  *(On some phones it’s under Security or Apps & notifications.)*
- Tap the app you used to download the file (Chrome, Files, Samsung Internet, etc.).
- Turn on **Allow from this source**.

### 3. Install the Game
- Open your **Files** app (or Downloads).
- Find **Netrunner IRL.apk** and tap it.
- Tap **Install**.
- When it finishes, tap **Open** (or find the game in your app drawer).

### Notes
- Android may warn that the file “could harm your device.” That’s normal for any APK that isn’t from the Play Store. Only install if you trust the source.
- Steps look slightly different depending on your Android version or phone brand (Samsung, Pixel, etc.), but the idea is the same: allow the downloader app to install APKs, then open the file.
